Zero to Phi

an indie game studio in Red Deer

Zero to Phi, founded by Justin Lewis, makes emergent, connected, visceral games: one simple connection point, lots of freedom inside the system, and mathematically clean rails underneath. The name runs from 0 to φ, the golden ratio.

Justin is a character animator based in Red Deer, Alberta, and a punk rock drummer who makes music. This is where the studio’s original games live — and where older versions stay up so you can visit a game as it has grown.
